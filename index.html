📖 규칙

차·포·마·상·사·졸/병·궁의 한국 장기 규칙과 궁성 대각선을 적용합니다.
포는 기물 하나를 넘어야 하며 포를 넘거나 잡을 수 없습니다. 마·상은 경로가 막히면 못 갑니다.
두 궁이 마주 보는 빅장은 양측 기물 점수(덤 제외)가 모두 30점 이하일 때만 둘 수 있으며, 상대가 다음 수에 해소하지 못하면 계가로 승패를 정합니다.
한수쉼은 장군 상태가 아닐 때 가능하며, 양쪽이 연속으로 쉬면 계가(차13·포7·마5·상3·사3·졸2, 한 덤 1.5)로 승패를 정합니다.
호스트 브라우저가 닫히면 방도 종료됩니다.

🔌 P2P 연결 방법

1. 방장이 방 만들기를 누르고 생성된 내 코드를 친구에게 보냅니다.

2. 참가자는 방 참가하기를 누르고 방장 코드를 붙여 넣어 코드 적용을 누르면 응답 코드가 생깁니다.

3. 참가자가 응답 코드를 방장에게 보냅니다.

4. 방장이 응답 코드를 붙여 넣고 코드 적용을 누르면 연결되어 대국 화면으로 넘어갑니다.

일부 엄격한 NAT/방화벽 환경에서는 직접 연결이 실패할 수 있습니다.
