📖 적용 규칙

차·마·상·포·졸/병·사·왕(장/한)의 기본적인 한국 장기 이동 규칙을 적용합니다.
포는 반드시 한 개의 기물을 뛰어야 하며 포를 뛰거나 포를 잡을 수 없습니다.
마·상은 중간 경로가 막히면 움직일 수 없습니다.
왕/사는 자기 궁 안에서 움직이고 궁성의 대각선도 사용할 수 있습니다.
장군은 상대 왕을 공격하는 상태이며, 그 상태에서 상대에게 합법적인 수가 없으면 외통수로 종료합니다.
서버 없는 P2P 특성상 호스트 브라우저가 닫히면 방도 종료됩니다.

🔌 P2P 연결 방법

1. 방장은 방 만들기를 누르고 생성된 내 코드를 친구에게 보냅니다.

2. 참가자는 방 참가하기을 누르고 방장의 코드를 입력한 다음 코드 적용을 누릅니다. 그러면 참가자용 응답 코드가 생성됩니다.

3. 참가자는 응답 코드를 다시 방장에게 보냅니다.

4. 방장은 받은 응답 코드를 붙여 넣고 코드 적용을 누릅니다. 연결되면 자동으로 초/한이 배정되고 대국이 시작됩니다.

이 방식은 시그널링 서버 없이 사람이 연결 정보를 전달합니다. WebRTC 특성상 일부 엄격한 NAT/방화벽 환경에서는 직접 연결이 실패할 수 있습니다.
